## Версия: 1.0
## Дата: 2026-01-16

---

## 📋 Краткое описание проекта

**Цель:** Создать полуавтоматическую веб-платформу для:
1. **Анализа и поиска прибыльных ниш** для контент-креаторов (глобальный охват: США, Европа)
2. **Автоматической генерации видео-контента** (Shorts, Reels, TikTok, YouTube 10-15 мин)

**Бюджет:** $200-1000/месяц
**Регион:** Английский контент (США/Европа)
**Режим работы:** Полуавтоматический с ручным подтверждением ключевых решений

## 🎯 МОДУЛЬ 1: Анализ и поиск ниш

### Функциональность

#### 1.1 Сбор данных о трендах (Автоматический)

**Источники данных:**
- **YouTube Data API v3** - анализ трендов, просмотров, комментариев
- **TikTok Creative Center API** - данные по вирусным видео
- **Google Trends API** - глобальные поисковые тренды
- **Reddit API** - анализ активности в сообществах
- **Twitter/X API v2** - мониторинг хештегов и обсуждений

**Метрики для анализа:**
- Объем поисковых запросов (Search Volume)
- Динамика роста интереса (Trend Growth %)
- Уровень конкуренции (Competition Score)
- Средний CPM и доход на 1000 просмотров
- Engagement Rate (лайки, комментарии, шеры)

#### 1.2 Оценка прибыльности ниши

**AI-анализ использует:**
- **OpenAI GPT-4o** ($0.005/1K tokens) - анализ контекста и трендов
- **Anthropic Claude 3.5 Sonnet** - глубокий анализ конкурентов

**Критерии оценки:**
```
Niche Score = (Search Volume × 0.3) +
              (Trend Growth × 0.25) +
              (Low Competition × 0.25) +
              (Monetization Potential × 0.2)
```

**Выходные данные:**
- ТОП-10 перспективных ниш
- Для каждой ниши:
  - Описание и примеры успешных каналов
  - Рекомендуемые форматы контента
  - Прогноз доходности ($300-5000/мес)
  - Уровень сложности входа (Low/Medium/High)
  - Ключевые хештеги и темы

## 🎬 МОДУЛЬ 2: Автоматическая контент-фабрика

### Функциональность

#### 2.1 Генерация идей контента (Автоматическая)

**После выбора ниши:**
1. AI генерирует **50-100 идей** для видео на основе:
   - Анализа успешного контента в нише
   - Актуальных трендов
   - Сезонности и событий
   - Часто задаваемых вопросов (FAQ analysis)

2. **Типы контента:**
   - **Shorts/Reels/TikTok** (30-60 сек):
     - Лайфхаки и советы
     - "До и после"
     - Быстрые обзоры
     - Реакции на тренды

   - **YouTube средний формат** (10-15 мин):
     - Обучающие видео
     - Детальные обзоры
     - Истории и кейсы
     - Интервью с AI-аватарами

#### 2.2 Создание сценариев (Полуавтоматическое)

**Workflow:**
```
1. AI генерирует сценарий →
2. Пользователь редактирует/утверждает →
3. Переход к производству
```

**AI-инструменты для сценариев:**
- **GPT-4o** - написание сценария, hooks, CTA
- **Claude 3.5 Sonnet** - проверка структуры и логики
- **Jasper AI / Copy.ai** - оптимизация под конверсию

**Структура сценария для Shorts:**
```
1. Hook (0-3 сек) - Зацепка
2. Problem (3-10 сек) - Проблема
3. Solution (10-45 сек) - Решение
4. CTA (45-60 сек) - Призыв к действию
```

**Структура сценария для 10-15 мин:**
```
1. Intro + Hook (0-30 сек)
2. Обещание ценности (30-60 сек)
3. Основной контент (2-12 мин, разделен на главы)
4. Резюме (1 мин)
5. CTA + Outro (30 сек)
```

#### 2.3 Производство видео (Автоматическое)

**A. Для коротких видео (Shorts/Reels/TikTok):**

**Рекомендуемые инструменты:**

1. **Pictory.ai** ($29/мес - Standard)
   - Автоматическое создание видео из текста
   - Библиотека stock-видео (3M+ клипов)
   - Автоматические субтитры
   - 30 видео/месяц

2. **Lumen5** ($19/мес - Basic)
   - AI-подбор визуалов к тексту
   - Шаблоны для соцсетей
   - Автоматический монтаж
   - 20 видео/месяц

3. **FlexClip** ($9.99/мес - Plus)
   - 100+ шаблонов
   - Text-to-video
   - AI voice-over
   - 50 видео/месяц

**Workflow коротких видео:**
```

Auto-edit (AI подбор кадров) →
Озвучка (ElevenLabs) →
Субтитры →
```

**Рекомендуемые инструменты:**

## 💻 Технический стек

### Frontend
- **Framework:** Next.js 14 (App Router)
- **UI Library:** React 18
- **Styling:** Tailwind CSS + shadcn/ui components
- **State Management:** Zustand
- **Forms:** React Hook Form + Zod validation
- **Charts:** Recharts / Chart.js

**Почему Next.js?**
- SSR для лучшего SEO
- API Routes для backend integration
- Отличная производительность
- Огромная экосистема

### Backend
- **Runtime:** Node.js 20 LTS
- **Framework:** Express.js или Fastify
- **API:** RESTful + WebSocket (для real-time статусов)
- **Authentication:** NextAuth.js (OAuth + Email)

### База данных
- **Primary DB:** PostgreSQL 16
  - Таблицы: users, niches, videos, analytics, content_ideas
  - JSONB для хранения метаданных AI-анализа
- **Cache:** Redis 7
  - Кэширование API-ответов (Google Trends, YouTube)
  - Session store
  - Job queue (Bull/BullMQ)

### Очереди и фоновые задачи
- **BullMQ** + Redis
  - Генерация видео (долгие задачи)
  - Анализ ниш (ежедневные задачи)
  - Автопостинг

### AI Orchestration
- **LangChain** - для оркестрации AI-запросов
- **OpenAI SDK** - GPT-4o интеграция
- **Anthropic SDK** - Claude интеграция

### DevOps
- **Hosting:**
  - Frontend: Vercel (бесплатный tier для начала)
  - Backend: Railway ($5-20/мес) или DigitalOcean ($24/мес - 4GB)
  - DB: Supabase ($25/мес - Pro) или Railway
- **CI/CD:** GitHub Actions
- **Monitoring:** Sentry (ошибки) + Vercel Analytics

### Хранилище файлов
- **AWS S3** или **Cloudflare R2** (~$5-10/мес для 100GB)
  - Хранение готовых видео
  - Thumbnails
  - Assets
