# 🐍 Crypto Snake - Liquid Glass Edition

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Современная веб-версия классической игры "Змейка" с интеграцией MetaMask кошелька и потрясающим Liquid Glass дизайном.

## ✨ Особенности

### 🎮 Игровая механика
- **Классический геймплей** с современными улучшениями
- **Динамическая сложность** - игра ускоряется с каждым уровнем
- **Система начисления очков**:
  - Базовые очки: 10 за каждую еду
  - Бонус за уровень: +5 очков за каждый уровень
  - Бонус за длину: +2 очка за каждые 5 сегментов
- **Плавные анимации** и эффекты частиц
- **Система уровней** - новый уровень каждые 100 очков

### 💎 Liquid Glass Design
- **Glassmorphism** эффекты с размытием фона
- **Градиентные переходы** и анимации
- **Прозрачные панели** с эффектом матового стекла
- **Динамический фон** с плавными анимациями
- **Неоновые эффекты** и свечение элементов

### 🦊 MetaMask Integration
- **Подключение кошелька** одним кликом
- **Отображение адреса** кошелька
- **Автоматическое переподключение** при смене аккаунта
- **Поддержка всех сетей** Ethereum, Polygon, BSC и др.
- **Привязка рекордов** к адресу кошелька

### 🎵 Звуковые эффекты
- **Web Audio API** для генерации звуков
- **Динамические звуки**:
  - Поедание еды
  - Повышение уровня
  - Конец игры
- **Возможность отключения** звука

### 📊 Система рекордов
- **Топ-10 рекордов** с детальной информацией
- **Сохранение в localStorage** - данные не теряются
- **Отображение достижений**:
  - Счёт
  - Длина змейки
  - Достигнутый уровень
  - Дата и время
  - Адрес кошелька (если подключен)

### 📱 Адаптивный дизайн
- **Полная поддержка мобильных** устройств
- **Свайп-управление** для тач-экранов
- **Кнопки управления** для мобильных
- **Автоматическая адаптация** размера canvas
- **Оптимизация для планшетов**

## 🎮 Система начисления очков

Очки начисляются по следующей формуле:

```javascript
базовые_очки = 10
бонус_уровня = (уровень - 1) × 5
бонус_длины = floor(длина_змейки / 5) × 2

итого = базовые_очки + бонус_уровня + бонус_длины
```

**Пример**:
- Уровень 3, длина змейки 12
- Очки = 10 + (3-1)×5 + floor(12/5)×2
- Очки = 10 + 10 + 4 = **24 очка**
